# Microscopy Flat-Field & Pseudo-Flat-Field Illumination Correction (`microscopy-flatfield-correction`)

A scientific Python CLI and AI Agent Skill for microscopy illumination correction with **bit-depth preservation (`uint8`/`uint16`)**, **foreground-resistant background estimation**, **shared luminance gain for color ratio retention**, and **independent machine-readable Quality Control (QC) reporting**.

> [!IMPORTANT]
> **Core Principle: Lossless File Encoding != Unaltered Pixel Values (`文件编码无损 ≠ 图像像素内容未改变`)**
> Saving outputs using **lossless file encoding** (`.tif` or `.png` lossless compression) only prevents file-compression artifacts. Illumination correction itself alters pixel values. Users must distinguish between **Mode A (`flatfield`, true instrument calibration)** and **Mode B (`pseudo-flatfield`, low-frequency background approximation)** before performing downstream quantitative analysis.

## 🧭 Mode A vs. Mode B: Which Mode Can Be Used for Quantification?

| Feature / Criterion | Mode A: True Flat-Field (`--mode flatfield`) | Mode B: Pseudo-Flat-Field (`--mode pseudo-flatfield`) |
| :--- | :--- | :--- |
| **Physical Basis** | Instrument calibration using measured flat-field reference $F$ and optional dark-field $D$ | Approximate low-frequency background surface $\hat{B}(x,y)$ estimated from the sample image itself |
| **Required Inputs** | Sample $I_{\mathrm{raw}}$ + Flat-field $F$ (+ optional Dark-field $D$) | Sample $I_{\mathrm{raw}}$ only |
| **Supported Modalities** | Brightfield & Fluorescence | **Brightfield only** (Fluorescence / dark-background images are rejected by default) |
| **Visual Presentation** | Suitable | Suitable |
| **Fluorescence Intensity Quantification** | **Suitable** (when $F, D$ are unsaturated, linear, and matched in optics/exposure) | **Prohibited** (dividing by self-estimated background amplifies dark noise and distorts emitter flux) |
| **Stain Thresholding / Positive Area % / Optical Density (Oil Red O, DAB-IHC, H&E)** | Suitable with linear calibration; verify threshold stability | **Not suitable as direct quantitative evidence** unless independently validated against physical flat-field standards |

## 📐 Mathematical Principles

### 1. Mode A — Instrument Flat-Field Calibration (`--mode flatfield`)

Given raw image $I_{\mathrm{raw}}$, flat-field reference $F$, and optional dark-field $D$ (multi-frame inputs are aggregated via pixel-wise median):

$$
I_{\mathrm{corr}}(x, y) = \frac{\max\bigl(I_{\mathrm{raw}}(x, y) - D(x, y),\ 0\bigr)}{F(x, y) - D(x, y)} \times \mathrm{norm}(F - D) + I_{\mathrm{offset}}
$$

- **Per-Channel Calibration**: Applied per channel using paired reference channels (RGB samples require RGB references; mismatched channel counts raise an error).
- **Normalization Factor** $\mathrm{norm}(F - D)$: Defaults to $\mathrm{median}(F - D)$ over valid pixels (`--norm-stat median`, or `mean` via `--norm-stat mean`) to preserve native dynamic range without outlier sensitivity.
- **Dark Offset**: By default $I_{\mathrm{offset}} = 0$ (dark offset subtracted, recorded as `zero_offset_changed: true` in metadata). Pass `--keep-offset` to add back $\mathrm{median}(D)$.
- **Denominator Protection**: Where $F(x, y) - D(x, y) \le \tau_{\mathrm{denom}} \cdot \max(F - D)$ (default $\tau_{\mathrm{denom}} = 1\%$, `--denom-eps-rel 0.01`), pixels are left uncorrected ($\mathrm{gain} = 1.0$) and logged in the QC report (`INVALID_FLATFIELD_DENOMINATOR`).
- **Reference Auditing**: Automatically checks $F$ for sensor saturation (`REFERENCE_SATURATED`), localized high-frequency dust/bubble anomalies (`REFERENCE_HIGH_FREQUENCY_ARTIFACTS`), bit-depth match (`REFERENCE_BIT_DEPTH_MISMATCH`), and resolution match (mismatched sizes raise an error unless `--allow-resize` is explicitly passed).

### 2. Mode B — Pseudo-Flat-Field Approximation (`--mode pseudo-flatfield`)

When no physical reference $F$ is available, Mode B estimates a low-frequency illumination background $\hat{B}(x, y)$ at spatial scale $\sigma_{\mathrm{px}}$ (in pixels, `--sigma-px`):

$$
g(x, y) = \min\left(\frac{T}{\hat{B}(x, y)},\ g_{\max}\right), \qquad I_{\mathrm{corr}}(x, y) = I_{\mathrm{raw}}(x, y) \times g(x, y)
$$

- **Pixel-Scale Smoothing (`--sigma-px`)**: Specified in pixels (defaults to $\max(15.0,\ \min(H, W)/8)$). Objective magnification alone does not determine pixel size due to differences in camera pixel pitch, C-mount relay lenses, binning, and cropping. The default is only a starting point and must be verified against biological feature sizes.
- **Foreground-Resistant Estimation (`--bg-method masked_gaussian`, default)**:
  1. Pre-filters coarse blocks to upper-percentile background candidates and fits a degree-4 2D polynomial trend via asymmetric Iteratively Reweighted Least Squares (IRLS), tracking large-scale vignetting/tilt into image corners without boundary reflection slope bias.
  2. Masks localized absorbing foreground features and hot-pixel outliers relative to the trend (enforcing scale consistency at $\sigma_{\mathrm{px}}$), and applies normalized Gaussian convolution with `reflect` boundary padding on background residuals.
  3. Naive unmasked Gaussian blurring is retained as `--bg-method gaussian` (emits `NAIVE_GAUSSIAN_BG` warning).
- **Shared Luminance Gain for RGB Images (default)**: Estimates $\hat{B}(x, y)$ from mean luminance $L = \frac{1}{3}(R+G+B)$ and multiplies all three channels by the same scalar gain $g(x, y)$, preserving RGB channel ratios ($R/G, B/G, R/B$). Note: shared luminance gain does **not** remove background color casts. Passing `--per-channel` normalizes each channel independently to the common median (emitting `PER_CHANNEL_COLOR_SHIFT` warning).
- **Native Dynamic Range Preservation**: Defaults to $T = \mathrm{median}(\hat{B})$, preserving native intensity scales for both `uint8` and `uint16` data. Passing `--target-val` overrides $T$.

## 🚀 Installation & CLI Usage

### Installation

```bash
git clone https://github.com/FrostGUU/microscopy-flatfield-correction.git ~/.gemini/config/skills/microscopy-flatfield-correction
cd ~/.gemini/config/skills/microscopy-flatfield-correction
pip install -r requirements.txt
```

### Mode A: True Flat-Field Calibration (`--mode flatfield`)

```bash
python scripts/correct_illumination.py single \
  --mode flatfield \
  --input-file "path/to/raw_16bit.tif" \
  --flatfield "path/to/flatfield_ref.tif" \
  --darkfield "path/to/darkfield_ref.tif" \
  --output-file "path/to/calibrated_16bit.tif" \
  --report-json "path/to/qc_report.json" \
  --print-summary
```

### Mode B: Pseudo-Flat-Field Approximation (`--mode pseudo-flatfield`)

```bash
# Single image
python scripts/correct_illumination.py single \
  --mode pseudo-flatfield \
  --input-file "assets/examples/sample1_4x_raw.png" \
  --output-file "assets/examples/test_output.png" \
  --sigma-px 75 \
  --print-summary

# Batch directory
python scripts/correct_illumination.py batch \
  --mode pseudo-flatfield \
  --input-dir "path/to/raw_images" \
  --output-dir "path/to/corrected_images" \
  --sigma-px 75
```

## ⚠️ Limitations 

1. **Multiplicative Model Assumptions (Mode A & Mode B)**: The flat-field division model assumes a **linear photon response** ($I = L \cdot T + D$), identical optical path (same objective, filters, focus, and camera ROI/binning), and absence of stray glare. If the flat-field reference $F$ contains dust motes, air bubbles, or sensor saturation, Mode A will imprint inverse artifacts onto the corrected image.
2. **8-Bit Gamma Encoding (`GAMMA_ENCODED_8BIT`)**: Standard 8-bit PNG/JPEG and color camera files are typically gamma-encoded (sRGB) rather than linear. Applying multiplicative gains in gamma-encoded space is an approximation and is flagged in the QC report.
3. **Foreground/Background Scale Ambiguity in Mode B**: Mode B cannot distinguish between illumination shading and confluent biological structures whose spatial extent exceeds `--sigma-px`. Choosing `--sigma-px` too small attenuates object contrast and creates bright boundary halos; choosing `--sigma-px` too large under-corrects steep corner vignetting. Both synthetic testing and visual/QC inspection are required when tuning `--sigma-px`.
4. **Shared Luminance Gain vs. Background Tint (Mode B)**: By default, Mode B applies a single luminance gain across R, G, and B to preserve channel ratios, which means background color casts (e.g., warm halogen lamp tint) are not removed. Using `--per-channel` neutralizes background tint but alters foreground stain channel ratios ($R/G, R/B$).
5. **Boundary Padding Effects**: Mode B uses `reflect` padding at image borders. Although polynomial detrending removes global slope reflection bias, dense dark structures touching image corners can still bias local corner gain estimates.
6. **Unsupported File Layouts**: Multi-page Z-stack/time-series TIFFs, channel-first `(C, H, W)` arrays, and floating-point input images are rejected with explicit error messages.
